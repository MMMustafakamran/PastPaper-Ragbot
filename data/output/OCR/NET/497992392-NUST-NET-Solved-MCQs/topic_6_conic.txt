(c) both axes
(d) line y = x Note. The symmetry of a curve. (i) If we get the same equation by replacing x by −x the curve is symmetric about the y-axis. (ii) If we get the same equation by replacing y by −y the curve is symmetric about the x-axis. (iii) If we get the same equation by replacing x by −x and y by −y, the curve is symmetric about the origin or about both the axes. (iv) If we get the same equation by interchanging x and y, the curve is symmetric about the line y = x.
